Validation of Half Sword Direct IP 0.2.2

Windows x64, LLVM-MinGW UCRT 20261104, C++20, Release (-O2).
C++ builds use -Wall -Wextra -Werror.

Passed automated checks:
- Real UDP host and two independent clients: membership, snapshots, chat,
  ready state, display-name updates, reliable 16 KiB and unreliable payloads.
- Capacity rejection, occupied port, timeout, kick/rejoin, host disconnect.
- Sender-bound name changes, control-character and UTF-8 length handling,
  protected host state, wrong-target filtering, 20,000 malformed frames.
- Mock UPnP mapping lifecycle and error paths; tests disable real UPnP.
- Roster identity preservation across renames; lobby scene, loadout-change,
  sever/recovery, gore, update and version regression programs.
- In the installed supported game, the direct equipment launcher created
  UI_Tavern_Inventory with valid preview character and camera references.
  Closing exported the Free Mode passport; opening, closing and reopening
  retained the host lobby without map travel. Tested through the opt-in,
  loopback-only agent bridge. No career-save writes were enabled.

0.2.2 preview correction:
- Main-menu visibility is saved, hidden during editing and restored on return.
- The editor selects its preview camera and restores the previous camera and
  control rotation on close. This patch needs an in-game visual recheck.

Limits:
- Visual layout and interactive equipment picking need a player check.
- Mid-round return/map travel and edited equipment need a two-player check.
- Internet play, physical-router UPnP and hardware audio were not retested.
- Dismemberment recovery improvements do not establish that every desync is fixed.

Game assets used for local inspection are not included in this repository.
